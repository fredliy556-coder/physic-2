# Физика 10

Приложение для изучения физики 10 класса и подготовки к ЕГЭ: теория по уровням (понять → запомнить → применить → проверить), карточки с интервальным повторением, задачи с проверкой ответа и подсказками, тренировка ЕГЭ и учебный вариант с таймером. Без сборки и внешних библиотек. Работает офлайн как PWA.

## Файлы
- `index.html` — разметка и данные курса (теория, формулы, величины, схемы, 470 задач, задания ЕГЭ, исходные карточки). Код старой версии оставлен в блоках `type="text/plain"` и не выполняется.
- `learn.js`, `learn2.js` — новый учебный контент по темам: простое объяснение, примеры из жизни, ошибки, разбор задачи, тест, концептуальные карточки, «какой закон применить»; связь номеров ЕГЭ с темами.
- `app.js` — хранилище и миграция прогресса, все типы карточек, SM-2, освоение тем, план дня, навигация.
- `check.js` — проверка числовых ответов (допуск 2%, единицы и приставки, поиск типичной ошибки), подсказки, баллы ЕГЭ.
- `views1.js` (главная, обучение, настройки), `views2.js` (карточки), `views3.js` (практика, диагностика, ЕГЭ).
- `sw.js` — офлайн-кеш. При изменении файлов увеличь `V`.

## Публикация на GitHub Pages
1. Создай репозиторий на github.com (например, `fizika10`) и загрузи туда все файлы из папки, включая `.github/workflows/pages.yml`.
   Через терминал: `git init && git add . && git commit -m "Физика 10" && git branch -M main && git remote add origin https://github.com/<ник>/fizika10.git && git push -u origin main`
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Workflow проверит синтаксис JS, сделает PNG-иконки и опубликует сайт: `https://<ник>.github.io/fizika10/`.

## Установка на iPhone
Открой адрес в Safari → «Поделиться» → «На экран Домой». После первого открытия всё, кроме видео и внешних ссылок, работает без интернета.

Прогресс хранится в браузере устройства. Копию можно сохранить и загрузить в настройках.
